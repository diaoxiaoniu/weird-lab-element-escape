# 怪奇实验室：元素逃亡

一款基于 Godot 4.3+ 的 2D 探索 + 化学解谜冒险游戏。

## 项目简介

在这个实验室逃生游戏中，玩家需要在 2D 实验室场景中探索、与物品交互，并运用化学知识解决各种谜题，帮助角色逃离危险的实验室。

## 角色

- **芮克森·玻尔** (Rixen) - 主角，化学天才
- **莫里·离子** (Mori) - 搭档，实践派化学家（玩家控制）
- **维稳协议** (System) - AI系统

## 游戏玩法

### 探索模式
- 在 2D 实验室场景中自由移动
- 与环境中的物品和设备交互
- 寻找线索和解决问题的工具

### 解谜模式
- 靠近热点按 **E** 键或**点击**进行交互
- 触发化学谜题对话界面
- 分析情况，选择正确的化学方案
- 查看提示，学习化学知识

## 如何运行

### 在 Godot 编辑器中运行

1. 确保已安装 Godot 4.3 或更高版本
2. 打开 Godot 引擎
3. 点击"导入"，选择本项目的 `project.godot` 文件
4. 导入完成后，项目会自动打开
5. 按 F5 键运行游戏

## 游戏操控

### 移动方式
- **WASD** 或 **方向键** - 键盘移动
- **鼠标左键点击** - 点击地面移动到目标位置

### 交互
- **E 键** 或 **Enter** - 与附近的物品交互
- **鼠标左键** - 点击物品直接交互（需在附近）

### 谜题界面
- **鼠标点击** - 选择选项
- **提示按钮** - 查看化学提示（部分提示需失败后解锁）
- **关闭按钮** - 退出谜题（可继续探索）

### 添加新关卡

关卡数据使用 JSON 格式存储在 `content/levels/` 目录下。

每个关卡文件包含：
- 标题和介绍
- 调查场景描述
- 提示信息（最多3个）
- 选项和结果
- 回顾和下一关信息

参考 `ch1_lv01_fire_edge.json` 的格式创建新关卡。

## Web 导出

### 准备工作
1. 在 Godot 编辑器中打开项目
2. 进入"编辑器" → "管理导出模板"
3. 下载 Godot 4.3 Web 导出模板

### 导出步骤
1. 点击"项目" → "导出"
2. 添加"Web"预设
3. 配置导出路径
4. 点击"导出项目"

## 项目结构

```
.
├── project.godot              # Godot 项目配置
├── README.md                  # 项目说明
├── assets/                    # 资源文件
│   ├── icon.svg              # 项目图标
│   ├── lab_bg_placeholder.png           # 实验室背景（占位符）
│   ├── portrait_rixen_placeholder.png   # 芮克森肖像（占位符）
│   └── portrait_mori_placeholder.png    # 莫里肖像（占位符）
├── content/                   # 游戏内容数据
│   ├── chars/                # 角色配置
│   │   └── characters.json
│   └── levels/               # 关卡数据
│       └── ch1_lv01_fire_edge.json
├── scripts/                   # 游戏脚本
│   ├── level_loader.gd       # 关卡加载器
│   ├── player.gd             # 玩家控制器
│   ├── hotspot.gd            # 热点交互
│   ├── exploration_scene.gd  # 探索场景控制
│   └── puzzle_overlay.gd     # 谜题覆盖层
└── scenes/                    # 场景文件
    ├── exploration_scene.tscn # 主场景（探索模式）
    ├── puzzle_overlay.tscn    # 谜题UI覆盖层
    ├── player.tscn            # 玩家角色
    ├── hotspot.tscn           # 可交互热点
    └── level_player.tscn      # 原纯对话版本（已弃用）
```
